# Amaljith A S — DevOps & Cloud Portfolio

Production-ready, ultra-premium personal developer portfolio for **Amaljith A S**, DevOps & Cloud Engineer. Built with React 19, TypeScript, Tailwind CSS v4, and Framer Motion.

## 🚀 Key Features

- **Modern Aesthetic**: Glassmorphism paneling, vibrant HSL/OKLCH color gradients, glowing spotlights, and dark mode tokens.
- **Interactive Canvas Particles**: Lightweight GPU-accelerated particle canvas reactively responding to mouse movement.
- **DevOps & Cloud Focus**: Dedicated sections detailing Linux Administration, Docker Containerization, Kubernetes, Nginx Reverse Proxying, and Prometheus/Grafana Monitoring Stacks.
- **Project Showcase**: Detailed cards and modal architectures for:
  1. *Verdict Flow* (Legal Case Filing & Asynchronous Workflow Automation)
  2. *Women Safety Mobile Application* (Real-Time IoT & Geolocation Alerts)
  3. *Linux System Administration & Hardening* (Systems, Security & Bash Automation)
  4. *Containerized Observability & Nginx Stack* (Prometheus, Grafana, Node Exporter & Docker Compose)
- **Hanging Lanyard ID Pass**: Interactive 3D spring pendulum profile card physics (`AKUMENBYQ · INTERN PASS`).
- **Interactive Contact Hub**: Direct mail client & WhatsApp message generator + social links (LinkedIn, GitHub).
- **Resume Generator**: Built-in dynamic HTML resume builder & automatic downloader.
- **Full SEO & Accessibility**: Semantic HTML5, JSON-LD Schema.org metadata, Open Graph cards, ARIA labels, and responsive layout across all device viewports.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 7
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism Utilities
- **Animations**: Framer Motion 12
- **Icons**: Lucide React + React Icons

## 💻 Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```
